## 2. Trust boundaries

- B1 visitor browser (Sites sandbox iframe, github.io origin) -> GitHub Pages `forms.json` (config fetch).
- B2 visitor browser -> `docs.google.com/forms/d/e/<id>/formResponse` (anonymous no-cors POST).
- B3 **anyone on the internet -> formResponse directly** (no widget, no honeypot, no fill time; the endpoint is
  public in forms.json). This is the real input boundary; every client-side check is advisory.
- B4 Google Forms -> linked inbox sheet (Google writes the row; our code does not control that write).
- B5 submit trigger (runs as Daniel) -> MailApp -> Daniel's Gmail; Daniel's reply -> submitter (Reply-To).
- B6 Daniel / supervisor -> public repo (`data/forms.json`, forms-core.js); push token (SR-13, inherited).
- B7 editors of the Song Database / of the forms -> bound script project and form settings.

  XPosts.gs fine-grained token can write to danyeloz-embeds.
