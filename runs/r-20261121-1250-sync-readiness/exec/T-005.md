## Public API (window.OZSync) for T-007 / T-008 / T-009

Constants: `SHEET_ID, BASE, MOODS, GENRES, VOCALS, KEYS, TEMPOS ['Any','Slow','Medium','Fast'], BADGES [[field,label]...] (instrumental, clean, stems, cut60 '60 s', cut30 '30 s'), DEFAULTS, LINK_HOSTS, IMAGE_HOSTS, CONTACT_HOSTS, EMAIL_RE, NEED`.

| Function | Returns |
|---|---|
| `load()` | Promise `{ok, songs, settings}`: fetches tracks, Sheet1, sync_settings. `ok:false` means show the fallback message. |
| `fetchTab(name, heads?)` | Promise `{head, rows, ok}`; rows empty unless the headers in `heads` (default `NEED[name]`) exist |
| `parseCsv(text)`, `hasHeads(tab, heads)`, `tabUrl(name)` | helpers |
| `songs(tracksTab, sheet1Tab, now?)` | released songs, newest first; each: `isrc, title, artist, duration, explicit, language, release, released, bpm (int or null), tempo, key, moods[], genre, genre2, vocal, writers, producers, instrumental, clean, stems, cut60, cut30, featured, badges[], cover, links{spotify, apple, youtube, bandcamp}, listen, complete` (all URLs already safe or '') |
| `filter(songs, {q, mood, genre, vocal, tempo, key, language, has:[badge fields]})` | filtered list; unknown values ignored |
| `pickOneSheet(songs)` | one-sheet rows (8 to 10, or fewer if not available) |
| `settings(tab)` | D-5 merged settings; `one_stop` boolean; invalid email -> default; contact_url '' unless D-10 host; `from_sheet` |
| `rightsText(settings?)`, `processText(settings?)` | the exact wording; with no argument, D-5 defaults (T-009 copies `rightsText()` / `processText()`) |
| `contactHref(settings, title)` | https contact_url, or the mailto, or '' |
| `safeUrl(u, hosts)`, `safeLink(u)`, `coverUrl(u)`, `contactUrl(u)`, `validEmail(e)` | the only URL gates; use for every href/src |
| `el(tag, cls, text)` | element with textContent only |
| `released, flag, inList, moodList, bpmOf, tempoOf, complete, norm, today` | value helpers |

Default texts:
- rights: "One-stop clearance. Danyel OZ, LLC owns 100% of the master recordings and 100% of the publishing, so one agreement clears both sides. Songs are registered with a performing rights organization."
- process: "To license a song, send a request with the song, your project, the media, the territory and the term. You get a quote within 3 business days. We sign a simple license, and the files are delivered after signing: WAV plus instrumental, clean, stems or cutdowns where available."

Consumers must still: set `referrerpolicy="no-referrer"` on images, `target="_blank" rel="noopener noreferrer"` on external links (none on mailto), never use innerHTML with data, read no URL params that change content (SR-10).

## Deviations

1. Email pattern: SR-04 strict regex used. Sync.gs `SY_EMAIL_RE` (T-004) is looser (`[^\s@<>"',;:()\[\]\\]+@...`); an address Sync.gs accepts but sync-core rejects (e.g. `a?b@c.co`) makes the widget fall back to the D-5 default email. Follow-up for T-004/QA to align.
2. `process_note`, when set, is appended as a final sentence of `processText` (plan wording did not place it).
3. Both `safeUrl(u, hosts)` (SR-02 name) and `safeLink(u)` (DoD name) exist; `safeLink` = `safeUrl(u, LINK_HOSTS)`.
4. SR-11 "is1-ssl.mzstatic.com to is5-ssl.mzstatic.com" read as the range is1..is5 (all accepted as-is, no rewrite).
5. Join: `first_upc` = `song_upc` (digits), falling back to `isrc` = `song_ISRC` when the UPC has no Sheet1 row.
6. `filter` also accepts `key`, `language`, `has` (availability badges) beyond mood/genre/vocal/tempo/search.
