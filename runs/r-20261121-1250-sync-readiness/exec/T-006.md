## Deviations and decisions (declared)

1. getSyncAdmin is loaded when the Tracks screen opens, not only when the tab opens, because the readiness and settings cards need it. It is still loaded once into `TK.sync`, and the tab reuses that load. The call is read-only.
2. SR-09 preview: the admin app cannot load sync-core.js (that would be an external script, see SR-13). `syRights()` therefore copies the fixed plan wording of `OZSync.rightsText`. This means the wording lives in two places. QA or T-011 should compare the two outputs.
3. The settings card also checks client-side for a blank rights holder, matching the server rule from T-004 deviation 2.
4. Copy from studio notes takes BPM/key from the open song's vault notes first, then from `hints`. BPM is rounded. A key that is not in the 24-key list is not copied, and the user is told why.
5. A planted value outside a list (for example an old vocal value) still shows in its select, so it is not hidden. The server rejects it on save.
6. Line endings: Edit normalised TracksApp.html and TracksViews.html to CRLF in the working copy. Git reports that it will store them as LF, so there is no content churn.
